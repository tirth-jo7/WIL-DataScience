## Student wellbeing RAG work

The `rag/` service implements a test-driven wellbeing navigation pipeline with:

- Ollama-based structured generation
- deterministic safety routing and clinical-scope guardrails
- verified-source attribution
- BM25 retrieval baseline inspired by Walert
- retrieval evaluation using known, inferred and out-of-KB student queries

See `rag/README.md` for setup, tests and architecture.
